# 2D C Game — Coin & Dodge

A minimal 2D arcade game written in C11 using SDL2.

## Prerequisites

Install the SDL2 development headers (only needed once):

```bash
sudo apt-get update
sudo apt-get install -y libsdl2-dev
```

## Build & Run

```bash
make run
```

## Controls

- **Move:** `W A S D` or Arrow keys
- **Restart (on Game Over):** `R`
- **Quit:** `Esc`
